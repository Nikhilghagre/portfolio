# SOLID + Design Patterns — hands on, in Node.js

We build ONE real app: an **Order Checkout System**,
and refactor it step by step.

## Roadmap

| Step | Folder            | What we learn |
|------|-------------------|---------------|
| 0    | `00-bad-design/`  | The god class. Everything wrong. |
| 1    | `01-srp/`         | **S**ingle Responsibility — split the god class |
| 2    | `02-ocp/`         | **O**pen/Closed — kill the if/else chains |
| 3    | `03-lsp/`         | **L**iskov Substitution — subclasses that lie |
| 4    | `04-isp/`         | **I**nterface Segregation — fat interfaces |
| 5    | `05-dip/`         | **D**ependency Inversion — depend on abstractions |
| 6    | `06-solid-final/` | All 5 together, working app |
| 7    | `07-patterns/`    | Design patterns on top of the SOLID base |

Run each step:
```
node 00-bad-design/run.js
```
